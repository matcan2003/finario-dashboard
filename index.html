Backup automatico nella cartella OneDrive

Scegli una volta un file nella tua cartella OneDrive: Finario vi scriverà una copia aggiornata dei dati.

DA CONFIGURARE

Funziona in Chrome/Edge su Windows con autorizzazione alla scrittura del file. Il file deve essere scelto dentro la cartella OneDrive sincronizzata. OneDrive poi carica quel file nel cloud. Se il browser revoca il permesso, sarà necessario selezionarlo di nuovo. Non è una sincronizzazione fra dispositivi: è un backup automatico dal PC verso un file.

Backup automatico non configurato. I dati restano salvati nel browser.

Finario salva subito i dati in questo browser. Dopo aver completato il collegamento OneDrive, i dati vengono sincronizzati nel tuo spazio applicazione OneDrive. Conserva comunque una copia di sicurezza privata.
